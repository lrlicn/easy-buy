# easy-buy 门店扫码购

线下服装门店小程序：顾客扫描衣物吊牌二维码进入商品页，挑选、加购并完成支付。

## 功能

- **扫码选衣**：首页扫码解析吊牌二维码中的商品 id，直达商品详情
- **商品列表**：店内衣物浏览，点击进入详情
- **商品详情**：颜色/尺码/数量选择，支持加入购物车或立即购买
- **购物车**：数量增减、删除商品、合计结算
- **支付**：门店自提订单确认，模拟支付成功（真实支付需接入后端后调用 `Taro.requestPayment`）

## 技术栈

- Taro 4 + React + TypeScript + Webpack5 + Sass

## 开发

```bash
npm install

# H5 浏览器调试
npm run dev:h5

# 微信小程序构建（dist 产物导入微信开发者工具）
npm run build:weapp
```

## 目录结构

```
src/
├── pages/       # 页面：index（首页/扫码）、detail（商品）、cart（购物车）、pay（支付）
├── store/       # 购物车全局状态
├── data/        # 商品数据
└── assets/      # 商品图片
```

## 真机预览

配置微信小程序 App ID 与代码上传密钥后，可通过工作台生成真机预览二维码；或用 `npm run build:weapp` 产物在微信开发者工具中预览调试。
